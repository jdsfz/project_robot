# project_robot

산업안전 보호장구 전달 자율주행 로봇 프로젝트의 ROS 2 워크스페이스입니다. 개발 기준 환경은 Ubuntu 24.04, ROS 2 Jazzy, Gazebo Harmonic입니다. 환경과 장비 세부 버전은 팀에서 확인해 확정합니다.

## 확보된 장비와 진행 상태

- 사용자가 확인한 보유 장비: [Raspbot V2 라즈봇](https://www.icbanq.com/P016515116), [Raspberry Pi 5 버전 IoT 키트](https://www.icbanq.com/P013149476)
- 팀원 전원이 Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic 설치를 완료했습니다.
- Raspberry Pi에 연결한 라즈봇의 수동 조작은 이미 동작합니다. examples/manual/manual_jiy.py는 수동모드 시험용 파일입니다. Flask 웹 UI와 Raspbot_Lib로 전진·후진·제자리 좌회전·제자리 우회전·정지와 카메라 서보를 시험하며, 정식 ROS 제어 노드나 Gazebo 연동 구현은 아닙니다. Pi의 OS·ROS 배포판과 Gazebo용 명령 연결은 별도 확인·구현이 필요합니다.
- 다음 기술 작업은 실물 치수·휠 배치·센서 위치를 확인해 Gazebo용 라즈봇 모델과 메카넘 구동을 구성하고, 실물 수동조작과 같은 명령 인터페이스로 기본 주행을 맞추는 것입니다.
- 안전 정지 기준과 1차 시연 범위는 팀 미팅에서 결정하기 전까지 미정으로 둡니다.

## 현재 범위와 상태

요구명세서 v0.1을 기준으로 구현과 시험을 단계적으로 진행합니다. 명세서의 담당자, 진행 상태, 측정 수치는 팀 합의와 시험 증거에 따라 갱신합니다.

현재 저장소에는 ROS 2 robot_teleop 패키지 골격, /cmd_vel 인터페이스 초안, 수동 조작용 시뮬레이션 예제가 있습니다. 사용자 확인 기준으로 Raspberry Pi에 연결한 실물 라즈봇 수동 조작은 이미 동작하며, Gazebo용 로봇 모델·메카넘 구동 설정은 추가 작업이 필요합니다. 자율주행, CCTV 보호장구 감지, 임무 전달·복귀, 안전 정지 등의 요구사항은 구현 완료로 간주하지 않습니다. examples/robot_arch_example/은 초기 폴더에 있던 Pi/Gazebo 학습·시연 자료이며 제품 구현이나 인수시험 통과 증거가 아닙니다.

1차 운용 범위는 팀 검토가 끝나기 전까지 확정안으로 취급하지 않습니다. 단일 층·로봇 1대·사용자 직접 수령은 초안이며, 대상 추적과 자동 충전은 포함 여부가 미정입니다. 계단과 위험구역은 1차 주행 대상에서 제외합니다.

## 개발 환경 및 빌드

ROS 2 Jazzy가 설치된 Ubuntu 24.04 환경에서 워크스페이스 루트 기준으로 실행합니다.

    source /opt/ros/jazzy/setup.bash
    cd ~/project_robot
    colcon build
    source install/setup.bash

빌드 결과(build/, install/, log/)는 Git에서 제외됩니다.

## 개발·검증 순서

요구명세서의 단계별 검증 흐름을 따릅니다.

1. 공통 환경과 실제 로봇·센서·모터 인터페이스를 확인합니다.
2. 수동 조작과 정지 동작을 검증합니다.
3. Gazebo에서 로봇 모델과 기본 구동을 확인합니다.
4. 위치 추정, 경로 계획, 장애물 대응을 단계별로 구현·검증합니다.
5. CCTV 감지와 전달 임무 흐름을 연결합니다.
6. 감지부터 복귀까지 통합 반복시험을 하고 운용·복구 문서를 갱신합니다.

각 요구사항은 ID, 구현 위치, 시험 시나리오, 결과와 증거를 연결해 관리합니다. 시험을 통과하지 않은 항목은 완료로 표시하지 않습니다. 시뮬레이션 통과와 실물 검증 결과도 구분합니다.

## 인터페이스

현재 확인된 속도 명령과 좌표 프레임 초안은 docs/interfaces/ros_interfaces.md에 있습니다. 명령 유효시간, 정지 동작, 상태·오류, 임무 식별자, 시각·좌표 규칙은 팀 합의 후 문서와 구현에 함께 반영합니다. ROS 토픽만으로 하드웨어 독립 정지가 보장된다고 간주하지 않습니다.

## 참고 자료와 안전

examples/ 자료는 구조 및 시연을 참고하기 위한 것입니다. 프로젝트 요구사항을 만족하는지 별도 검토하고 시험하기 전에는 실제 로봇의 안전 기능으로 사용하지 않습니다. 실제 산업 현장 적용에는 별도의 위험성 평가, 실물 검증, 운용 승인과 절차가 필요합니다.

요구사항 원본과 회의록은 저장소 외부에서 관리될 수 있습니다. 저장소에 관련 문서를 추가할 경우 문서 버전과 갱신 날짜를 명시하고, 요구사항 변경과 구현·시험 결과를 함께 추적합니다.
