# A 파트 — 로봇 기반·주행

문서 버전 0.1 · 작성 2026-11-20 · 담당: A 파트 담당자(jiyjjy)

Gazebo와 실물 라즈봇(Raspbot V2)에서 공통으로 쓰는 구동 기반을 만들고, 승인된 범위의 이동·정지·장애물 대응을 담당하는 파트입니다. 상위 기준은 [시스템 아키텍처 및 개발 계획](../../architecture/시스템_아키텍처_및_개발_계획.md) 5장 A 항목입니다.

## 다른 파트가 알아야 할 것 (요약)

- **C 파트에 제공:** 주행 상태, 위치 유효성, 성공·실패·취소, 오류·정지 사유 (메시지 형식은 [상세설계서 5장](상세설계서.md#5-파트-간-인터페이스-초안) 초안, 팀 합의 전 미확정)
- **C 파트에서 받음:** 이동 목표 위치, 좌표계, 임무 ID, 취소·만료 조건
- **B 파트와 공유:** 로봇 카메라 영상·카메라 서보, `map` 좌표계와 TF
- **공통 규약:** 속도 명령은 `/cmd_vel`(geometry_msgs/msg/Twist), 좌표계는 `map`·`odom`·`base_link` ([ROS 인터페이스 초안](../../interfaces/ros_interfaces.md))
