# 시험 자료

기능별 ROS 패키지 단위의 자동 시험은 각 패키지의 test/ 아래에 둡니다. 워크스페이스 수준의 통합 시나리오, 실행 설정, 로그와 결과 요약은 여기에 정리합니다.

시험 기록에는 요구사항 ID, 시나리오, 예상 결과, 실제 결과, 날짜, 코드·환경 버전, 장비·지도·설정, 증거 위치와 통과 여부를 남깁니다. 시뮬레이션 결과와 실물 결과를 구분하며, 증거 확인 전에는 요구사항을 완료 처리하지 않습니다.

아직 이 폴더에 프로젝트 인수시험 결과는 없습니다. 기존 시연 코드는 examples/에 있으며 시험 통과 증거를 대신하지 않습니다.
